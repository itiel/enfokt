# enfoKT

Un temporizador con sonidos de ambiente para Windows. Es gratis, no tiene anuncios, no pide
cuenta y no recoge tus datos.

**Descarga, instrucciones y cómo mandar comentarios:** [soyitiel.com/enfokt](https://soyitiel.com/enfokt/)

Este repositorio solo guarda los instaladores de cada versión, en
[Releases](https://github.com/itiel/enfokt/releases). La app avisa sola cuando hay una versión nueva.

Hecha por [Itiel López](https://soyitiel.com).
